LIFE DEVELOPMENT FOUNDATION

A Website Designed for More People

LDF aims to make its website clear, usable and accessible across devices and assistive technologies.

Our Approach

We aim to make our website easier to use by providing clear headings, keyboard-accessible navigation, readable colour contrast, descriptive links, meaningful image descriptions and layouts that adapt to different screen sizes.

We recognise that people access websites in different ways. We aim to improve the experience for people using keyboards, screen readers, mobile devices and other assistive technologies.

Known Limitations

Accessibility is an ongoing process. The website may contain features or content that do not yet work equally well for everyone. We will update this section as issues are identified through testing and user feedback.

Request Assistance

If you experience difficulty using this website, need information in another format or have a suggestion for improvement, please contact Life Development Foundation.

Please tell us which page or feature caused difficulty so we can better understand and address the issue.

Ongoing Improvements

We aim to review the website regularly, consider feedback from visitors and prioritise improvements that make our information and services easier to access.

We will avoid claiming full accessibility compliance unless it has been supported by appropriate testing.
